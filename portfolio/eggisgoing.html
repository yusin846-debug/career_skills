EGGISGOING · SELF-DIRECTED POC CONCEPT

회의가 끝난 뒤에도,
맥락과 다음 행동이 남도록.

미디어 제작의 회의 기록을 검토 가능한 문서와 후속 업무로 연결하는 멀티 에이전트 오케스트레이션을 기획했습니다.

문제 정의 · 워크플로 설계Amazon Bedrock 기반 설계Agentforce / CRM 확장 제안
에그이즈고잉은 에그이즈커밍에서 영감을 받은 가상 제작사입니다. 개인 기획 POC이며, 실제 기업의 의뢰·납품·상용 도입 사례가 아닙니다. 이 글은 설계와 검증 계획을 다루며 Bedrock 실환경 실행을 입증하는 구축 보고서가 아닙니다.

문제

회의 중 아이디어는 바뀌고, 결정과 보류 사항은 섞입니다. 요약 하나만으로는 제작 문서와 담당자의 다음 일을 안정적으로 만들기 어렵습니다.

접근

기록 → 해석 → 결정 → 문서 → 검증을 분리하고, 근거와 사람의 확인을 각 단계에 남깁니다.

01 · WORKFLOW DESIGN

다섯 에이전트, 하나의 검토 가능한 흐름

  1. 01전사 · 화자누가 무엇을 말했는지 정리하고 발언 근거를 보존합니다.
  2. 02맥락 · 아이디어 변경초기 제안과 수정된 방향, 변경 이유를 구분합니다.
  3. 03결정 · 할 일확정·보류·확인 필요를 분리하고 담당자와 기한의 빈칸을 드러냅니다.
  4. 04문서 구성정해진 제작 템플릿에 맞춰 내용과 근거를 배치합니다.
  5. 05검증누락과 충돌, 근거 없는 결정이 없는지 확인합니다.
  6. OUTPUT결정적 DOCX 렌더러검토된 구조 데이터를 고정 형식의 문서로 변환합니다.

에이전트의 판단과 문서 형식 생성을 분리했습니다. 문서가 매번 다른 형식으로 나오는 문제는 렌더러에서, 내용의 불확실성은 검토 단계에서 다루는 설계입니다.

02 · HUMAN CONTROL

자동화할 일과 사람이 결정할 일의 경계

근거가 모자라거나 발언이 충돌하면 HumanTask로 확인을 요청합니다. 문제가 생긴 단계만 다시 실행하는 부분 재시도, 입력·출력 버전, 근거와 감사 기록을 남기는 구조를 기획했습니다.

최초 MVP는 프로그램 하나·템플릿 하나·최종 산출물 하나로 제한합니다. 먼저 작은 범위에서 정확성과 검토 부담을 확인한 뒤 확장을 판단합니다.

03 · PROPOSED CRM EXTENSION

AWS의 흐름을 유지하며, 고객 업무로 확장하기

이 기획의 출발점은 Agentforce가 아니라 Bedrock 기반 에이전트 오케스트레이션입니다. 기존 AWS 흐름을 일괄 전환하는 대신, MCP/API를 통한 Agentforce·Salesforce 연계를 후속 확장안으로 제시합니다.

예를 들어 협찬사·대행사의 요구사항을 고객과 영업기회의 맥락으로 관리하고, 회의에서 확인한 결정과 검토 완료된 할 일을 CRM Task 및 영업기회 후속 업무로 이어갈 수 있습니다. 실제 연계는 아직 구현하지 않았으며, 권한·객체 매핑·승인 기준과 연결 방식을 검증해야 합니다.

MCP/API는 가능한 연결 방식에 대한 제안입니다. 기존 AWS 워크플로, Agentforce 호출 권한, 데이터 접근 범위를 검토하고 사람이 승인한 항목만 후속 업무로 반영하는 것을 전제로 합니다.
04 · VALIDATION PLAN

효율을 주장하기 전에, 먼저 측정하기

기존 업무 약 4.5시간은 기억에 기반한 추정치이며, 2시간 이내는 검증할 목표입니다. 화면에 표현한 1시간 52분은 가상 예시로 실제 달성 실적이 아닙니다.

파일럿에서는 동일한 입력으로 수작업 대비 총 소요 시간, 사람이 수정한 항목, 결정·할 일의 누락, 근거 추적 가능성을 비교할 계획입니다. 속도뿐 아니라 검토를 마친 산출물의 품질로 도입 가치를 판단하고자 합니다.

05 · WHY THIS MATTERS

기술을 설명하기보다, 도입할 이유를 구체화하기

B2B 솔루션 영업에서 익힌 문제 정의를 AI 도입 기획으로 확장했습니다. 고객이 어디에서 시간을 쓰고, 어떤 결정을 직접 해야 하며, 작은 POC로 무엇을 확인할지를 먼저 정리하는 접근입니다.

기술 학습과 설계 역량은 실제 영업 경험을 보완합니다. 이 기획을 상용 구축 성과나 기존 SaaS AE 실적으로 바꾸어 설명하지 않습니다.
