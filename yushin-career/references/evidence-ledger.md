# Evidence ledger

포트폴리오·이력서에 쓰기 전 사실을 확정하기 위한 작업 기록. 이 문서의 내용은
대부분 **사용자 구술 기준의 잠정 기록**이며, 각 항목의 확인 상태를 별도로 표시한다.
확인되지 않은 항목을 지원 서류에 쓰지 않는다.

확인 상태 표기:
- `[확인됨]` — 문서·링크·제3자 자료로 뒷받침됨
- `[구술]` — 사용자 진술만 있음. 검증 전
- `[상충]` — 사용자 진술과 외부 기록이 어긋남. 확정 필요
- `[미확인]` — 아직 질문하지 않았거나 답이 오지 않음

> **세션 제약:** 이 작업 환경의 네트워크 프록시가 외부 웹페이지 접근을 차단한다.
> 기사 본문과 이미지를 직접 열 수 없으며, 검색 엔진의 요약만 확인 가능하다.
> 아래 `[검색요약]` 표시된 내용은 2차 출처이므로 원문으로 재확인해야 한다.

### ⚠ 상충 항목 — 최우선 확정 대상

**사용자 진술:** "SKT 전국대학교대상 스타트업 공모전 → 대상"

**검색 결과:** "2017년에는 경희대 창업 공모전에서 **대상**을 받았고 그해
**SKT 청년비상프로그램에 전국 대학 중 TOP7**에도 선정됐으며"

두 개의 별개 사건이 하나로 합쳐졌을 가능성이 있다. 9년 전 일이므로 기억 병합은
자연스러우나, 자격 이력은 리크루터가 실제로 검증하는 항목이다.

- "SKT 전국 공모전 대상"과 "교내 공모전 대상 + SKT 전국 TOP7"은 검증 결과가 다르다.
- 자격 하나가 어긋나면 나머지 전체의 신뢰가 함께 무너진다.
- **부풀릴 필요가 없다.** 실제 기록(법인 전환, 정부·은행 지원, VC 투자)만으로 충분히 강하다.

원문 기사 또는 수상 증빙으로 확정할 것.

### B2B 증거 후보

**검증 전이므로 아직 문장화하지 말 것.**

| 증거 | 왜 강한가 | 필요한 확인 |
|---|---|---|
| 카테고리 리포지셔닝 | "자판기 커피 = 싸구려"라는 시장 인식 자체를 공략. 단순 대체가 아니라 포지셔닝 설계 | 본인이 이 판단에 관여했는가 |
| 기존 공급자 교체 | 자판기 사업자가 있던 자리를 대체. B2B 최고 난도 동작 중 하나 | 기존 업체 존재 여부, 교체 논리 |
| 기관 구매자 상대 계약 | 대학생협은 이사회·조합원 구조. 멀티 스테이크홀더 딜 | 의사결정 구조, 설득 대상, 대학 수 |
| 제3자 관문 통과 | 공모전 → SKT 선정 → 청창사 → 정부·은행 지원 → VC 투자 | 각 단계 공식 명칭·연도 |
| 딜리버리 범위 | 공간디자인이 사업 영역에 포함 = 영업 후 구현까지 | 본인이 이 영역을 맡았는가 |
| B2C→B2B 전환 | 캠퍼스에서 오피스 사내카페로 고객군 이동 | 본인의 관여 시점과 범위 |

### 리스크 메모

- 2026년 기준 7~10년 전 경험. 최신 경력이 더 강하면 리드 케이스로 쓰지 않는다.
- 회사는 사용자 이탈 후에도 계속 운영된 것으로 보인다. **재직 기간 중 성과와
  이후 회사 성과를 반드시 분리**해야 한다. 회사의 누적 실적을 본인 실적으로 쓰지 않는다.
- 창업자 정체성이 아니라 **수행한 영업·운영 활동**으로 번역한다.
  "창업했다"가 아니라 "기관 구매자를 상대로 기존 공급자를 교체하는 계약을 만들었다".
- 3인 공동창업이므로 단독 기여로 서술하지 않는다.
